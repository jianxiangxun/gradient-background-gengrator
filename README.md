# Gradient Background Generator

A powerful Next.js application for creating stunning SVG gradient backgrounds with real-time preview and customizable color palettes. Features an innovative **Color Wheel** interface with both free selection and AI-powered color harmony recommendations.

## Features

- **Real-time Preview**: See your gradient backgrounds update instantly as you modify colors
- **Interactive Color Wheel**: Visual color selection with drag-and-drop interface
- **Dual Selection Modes**:
  - **Free Selection Mode**: Manually choose any two colors on the color wheel
  - **Recommendation Mode**: AI-powered color harmony suggestions based on color theory
- **Color Harmony Algorithms**: Supports 7 harmony types including complementary, analogous, triadic, split-complementary, tetradic, square, and monochromatic
- **Smart Recommendations**: Automatically suggests the best harmony type based on your base color
- **Preset Templates**: Choose from professionally designed color combinations
- **API Integration**: Generate gradients programmatically via REST API
- **SVG Export**: Download your creations as high-quality SVG files
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## Color Wheel Feature

### Free Selection Mode
In free selection mode, you can:
- Drag two color selectors (marked as "1" and "2") anywhere on the color wheel
- The color wheel displays the full HSL color spectrum
- Colors update in real-time as you drag
- The gradient is automatically generated from the two selected colors

### Recommendation Mode
In recommendation mode, the system helps you create harmonious color combinations:

1. **Select a base color** by dragging the first selector
2. **Choose a harmony type** from the dropdown:
   - **Complementary**: Colors opposite on the color wheel (high contrast)
   - **Analogous**: Colors adjacent on the color wheel (harmonious)
   - **Triadic**: Three evenly spaced colors (balanced)
   - **Split-Complementary**: Base color plus two colors adjacent to its complement
   - **Tetradic**: Two complementary color pairs (rich and diverse)
   - **Square**: Four evenly spaced colors (balanced variety)
   - **Monochromatic**: Variations of a single hue

3. **Smart Recommendations**: Click "Smart Recommend" to let the system choose the best harmony type based on your base color's hue and saturation

4. **Apply Recommendations**: Click on any recommended color swatch to set it as your second color

### Color Harmony Algorithm

The color harmony system is based on established color theory principles:

- **Hue Rotation**: Colors are generated by rotating the hue angle on the color wheel
- **Saturation & Lightness**: Preserved from the base color for consistency
- **WCAG Contrast**: All generated colors maintain readable contrast ratios

## API Usage

Generate gradients programmatically using the REST API:

```
GET https://gbg.nuclearrockstone.xyz/api?colors=hex_FF0000&colors=hex_00FF00&width=800&height=600
```

### Parameters:
- `colors`: Hex colors with `hex_` prefix (e.g., `hex_FF0000` for red)
- `width`: Image width in pixels (100-2000)
- `height`: Image height in pixels (100-2000)

## Technical Details

### Color Harmony Implementation

The color harmony system uses HSL (Hue, Saturation, Lightness) color space for intuitive color manipulation:

- **Hue**: 0-360 degrees on the color wheel
- **Saturation**: 0-100% (gray to full color)
- **Lightness**: 0-100% (black to white)

Harmony angles are defined as offsets from the base hue:
- Complementary: 0°, 180°
- Analogous: 0°, 30°, -30°
- Triadic: 0°, 120°, 240°
- Split-Complementary: 0°, 150°, 210°
- Tetradic: 0°, 60°, 180°, 240°
- Square: 0°, 90°, 180°, 270°

### Smart Recommendation Logic

The system recommends harmony types based on:
- **Saturation**: Low saturation → Monochromatic
- **Hue ranges**:
  - Red (0-30°, 330-360°) → Complementary
  - Orange/Yellow (30-90°) → Analogous
  - Green (90-150°) → Triadic
  - Cyan (150-210°) → Split-Complementary
  - Blue (210-270°) → Tetradic
  - Purple (270-330°) → Square
